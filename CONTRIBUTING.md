# Contributing to Agentic BOM Engineering for MedTech

Thank you for your interest in contributing to this book! This repository contains a practical guide for applying agentic automation to BOM management in medical technology organizations.

## How to Contribute

### Types of Contributions

1. **Content Improvements**
   - Fix typos, grammar, or clarity issues
   - Add examples or case studies
   - Expand on existing chapters
   - Suggest new topics or sections

2. **Technical Contributions**
   - Improve build and test infrastructure
   - Add diagrams or visualizations
   - Create example code or scripts
   - Enhance documentation

3. **Feedback**
   - Report issues or inconsistencies
   - Suggest improvements
   - Share real-world experiences

### Getting Started

1. **Fork and Clone**
   ```bash
   git clone https://github.com/cpmcnamara/coursera.git
   cd coursera
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run Tests**
   ```bash
   pytest --verbose
   ```

### Making Changes

1. Create a new branch for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Make your changes to the relevant files in the `book/` or `docs/` directories

3. Ensure all tests pass:
   ```bash
   pytest --verbose
   ```

4. Commit your changes with clear, descriptive messages:
   ```bash
   git commit -m "Add section on X to Chapter Y"
   ```

5. Push to your fork and submit a pull request

### Content Guidelines

- Keep the focus on practical, engineering-first approaches
- Include real-world examples where possible
- Maintain consistency with existing chapter structure and tone
- Ensure technical accuracy, especially regarding regulatory requirements
- Use clear, concise language appropriate for the target audience (R&D engineering managers, PLM/ERP architects, etc.)

### Code of Conduct

- Be respectful and professional
- Focus on constructive feedback
- Welcome newcomers and help them contribute
- Value diverse perspectives and experiences

## Questions?

If you have questions about contributing, please open an issue for discussion.

Thank you for helping improve this resource for the MedTech engineering community!
